# Proyecto-de-caminabilidad

Este es un respaldo del repositorio "Proyecto-de-caminabilidad" realizado por Crisol Baltazar Martínez, Azul Erendira Bravo Zazueta y Nixi Osornio Mejía.
El repositorio original se puede visualizar por medio del siguiente link: https://github.com/Nixi-Osornio/Proyecto-de-caminabilidad.git

He aquí una descripción de lo que podrá encontrarse en este directorio:

__Calculo_de_indicadores:__ Carpeta que contiene los cálculos realizados en PostgreSQL para cada subíndice.

__Pagina_web:__ Carpeta que contiene todos los archivos que conforman la página web desarrollada, junto un video demostrativo.

__Trabajo_de_campo:__ Carpeta que contiene fotografías tomadas durante el trabajo de campo, así como el documento con las fichas técnicas de los indicadores.

__Documento_Proyecto_Caminabilidad:__ Documento pdf que contiene toda la documentación oficial del proyecto.
