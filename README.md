# Proyecto-de-caminabilidad

Este es un respaldo del repositorio "Proyecto-de-caminabilidad" realizado por Crisol Baltazar Martínez, Azul Erendira Bravo Zazueta y Nixi Osornio Mejía.
El repositorio original se puede visualizar por medio del siguiente link: https://github.com/Nixi-Osornio/Proyecto-de-caminabilidad.git

He aquí una descripción de lo que podrá encontrarse en este directorio:
Calculo_de_indicadores: Carpeta que contiene los cálculos realizados en PostgreSQL para cada subíndice.
Pagina_web: Carpeta que contiene todos los archivos que conforman la página web desarrollada, junto un video demostrativo.
Trabajo_de_campo: Carpeta que contiene fotografías tomadas durante el trabajo de campo, así como el documento con las fichas técnicas de los indicadores.
Documento_Proyecto_Caminabilidad: Documento pdf que contiene toda la documentación oficial del proyecto.
